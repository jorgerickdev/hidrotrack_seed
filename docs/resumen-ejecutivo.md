# Resumen Ejecutivo

## HydroTrack Seed

HydroTrack Seed es una aplicación web desarrollada como parte de la Actividad 3 de la asignatura Desarrollo de Aplicaciones en Red. El proyecto tiene como objetivo aplicar de forma práctica los conocimientos relacionados con el consumo de APIs REST, el desarrollo basado en componentes, el procesamiento de información y la construcción de interfaces web modernas.

La aplicación utilizará información pública procedente del portal de datos abiertos del Gobierno de España para consultar precios de carburantes y datos asociados a estaciones de servicio. A partir de esta información se ofrecerán herramientas de búsqueda, filtrado y análisis orientadas a facilitar la toma de decisiones por parte del usuario.

Desde el punto de vista académico, el proyecto busca demostrar la integración de diferentes tecnologías y conceptos estudiados durante el curso, incluyendo React para el desarrollo de la interfaz, AJAX para la comunicación con servicios externos, procesamiento de datos en formato JSON y técnicas de geolocalización proporcionadas por el navegador.

La solución se desarrollará como una aplicación de página única (SPA), estructurada mediante componentes reutilizables que permitan una arquitectura modular y escalable. Como funcionalidad principal, el sistema permitirá localizar estaciones de servicio, consultar información sobre precios y aplicar filtros para facilitar la búsqueda de resultados relevantes.

La aplicación deberá ser capaz de obtener automáticamente la ubicación del usuario mediante geolocalización. Adicionalmente, se incorporará una opción de introducción manual de ubicación para garantizar el acceso a la funcionalidad en situaciones donde la geolocalización no esté disponible o el usuario prefiera realizar búsquedas desde una ubicación distinta.

Además de cumplir los objetivos de la actividad, el proyecto constituye la primera iteración del proyecto transversal del grado denominado **Automatización y Gestión de Hidrocarburos**, por lo que se ha diseñado siguiendo criterios de mantenibilidad, accesibilidad, control de versiones y crecimiento progresivo.

## Metodología de Trabajo

El proyecto se desarrollará siguiendo una metodología ágil adaptada a un equipo unipersonal. El trabajo se organizará mediante incrementos funcionales que permitan obtener resultados verificables de forma progresiva.

Cada incremento incorporará una funcionalidad completa del sistema, comenzando por la infraestructura de desarrollo, seguido de la construcción de componentes, integración con la API, geolocalización, filtrado de información y documentación.

El progreso será controlado mediante:

- Requerimientos definidos.
- Criterios de aceptación.
- Bitácora de desarrollo.
- Control de versiones mediante Git.
- Revisiones periódicas de avance.
- Entregables verificables.

## Alcance Ejecutivo

El alcance de esta primera iteración se limita a la obtención, procesamiento y presentación de información pública sobre estaciones de servicio, incluyendo funcionalidades de consulta, filtrado y geolocalización.

Quedan fuera del alcance de esta fase aspectos como:

- Gestión de usuarios.
- Sistemas de autenticación.
- Bases de datos propias.
- Persistencia de información.
- Funcionalidades administrativas.
- Aplicaciones móviles nativas.

## Entregables Principales

Como resultado de la actividad se generarán los siguientes entregables:

- Aplicación web funcional.
- Repositorio Git con código fuente y documentación.
- Memoria técnica en formato PDF.
- Evidencias de desarrollo y pruebas.
- Documentación de análisis, planificación y arquitectura.

## Visión de Evolución

HydroTrack Seed ha sido concebido como la semilla tecnológica del proyecto transversal del grado.

La organización del código, la documentación y la arquitectura se han diseñado para facilitar su evolución mediante futuras iteraciones académicas.

Las funcionalidades desarrolladas durante esta actividad constituirán la base para futuras ampliaciones relacionadas con la gestión y automatización de hidrocarburos, permitiendo incorporar nuevos módulos sin afectar la estructura fundamental del sistema.
